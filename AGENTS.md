# AGENTS.md

## Sobre o projeto

Este repositório é um clone do **TabNews** (https://tabnews.com.br), desenvolvido como parte do **curso.dev** (https://curso.dev), com a proposta de ser construído **utilizando agentes de IA**.

O TabNews é uma comunidade brasileira focada em tecnologia e programação, criada por Filipe Deschamps, onde usuários publicam conteúdos e comentários, e os melhores são votados (via "TabCoins") e ganham destaque na página inicial. O código do TabNews original é open source.

## Stack

- **Next.js** 16 (App Router)
- **React** 19
- JavaScript (sem TypeScript)

## Comandos

- `npm run dev` — inicia o servidor de desenvolvimento
- `npm run build` — gera o build de produção
- `npm run start` — inicia o servidor de produção

## Convenções

- O idioma do projeto (README, commits, interface) é **português do Brasil**.
